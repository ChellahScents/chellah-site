# Chellah Scents Website

Chellah Scents provides tailored services across language, tech consulting, and 3D prototyping. This static site features multilingual support (EN/FR/AR) and a PayPal-integrated order form.

## Structure

- `index.html` – Landing page
- `about.html` – Company profile
- `services.html` – Services offered
- `order.html` – Request form with payment
- `contact.html` – Contact info and message form
- `assets/` – CSS, JS, and images
- `lang/` – Translation dictionaries

## Run Locally

1. Clone the repo
2. Open `index.html` in a browser
